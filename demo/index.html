演示操作说明

故事 1：连续点击窗口外右下角的主按钮，依次讲完四处变化、分组冲突、理论 OOM、A/B 方案、仿真缺口、Diff 与配置包导出。可点“上一步”回讲；A/B 方案在比较页或 Diff 页选择。

标题栏支持拖动与双击最大化；窗口边缘支持缩放。Ctrl+B 主侧栏、Ctrl+J 面板、Ctrl+P 文件搜索、Ctrl+Shift+P 命令面板、Ctrl+S 保存工程。

msAgent 通过一个 MindStudio MCP 入口向外部 Agent 提供能力。“领域能力”卡片管理同一入口中的工具分组，外部 Agent 只需配置一个服务地址。

IDE 中 S1 保留完整固定脚本；msAgent 中 S1–S6 均提供多轮示例历史对话。点击回答中的拓展卡，可在右侧切换已有 demo 截图；支持原图查看，切换主题时保留各自的预览标签。所有调用、日志、状态和指标均为演示数据，未连接真实模型、MCP 或远程训练。
