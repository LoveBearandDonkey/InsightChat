# MindStudio 2027 交互演示底座

本 demo 现维护于 InsightChat 仓库的 `demo/`。图标统一引用 `../src/pic/icon/`；示例工具清单、构造数据与截图说明均随本目录保存，不依赖私有规划仓。

GitHub Pages 从仓库根目录发布后，入口为 `https://lovebearanddonkey.github.io/InsightChat/demo/`；源码中的相对路径同时支持本地服务器与该项目子路径。

本地、无构建步骤的 HTML/CSS/JS 原型。请通过本地服务器打开，以启用真正的 Monaco 编辑器及其 worker：

```powershell
# 在仓库根目录运行，需要 Node.js
node demo/server.cjs
```

访问 http://127.0.0.1:2027/demo/ 。可在命令后添加其他端口。

Windows 下也可双击 `启动预览.cmd` 启动服务器，然后打开上述地址。

不要用 `file://` 地址评估编辑器观感：直接双击 HTML 时，为避开浏览器的文件安全限制，编辑区会回退为简易文本编辑层。

窗口拖动按 `requestAnimationFrame` 合并指针事件，移动期间仅更新 `translate3d`，松手后提交坐标；桌面边界和尺寸下限在手势开始时读取。边缘缩放同样按帧处理，窗口显示/最大化状态不变时不重建按钮 DOM。合成的 100 次连续移动检查中，移动阶段尺寸读取由 1000 次降为 0，显示状态回调由 100 次降为 0；这只验证 DOM 工作量，不是浏览器 FPS 或绘制耗时测量。已检查八方向缩放、边界、松手/取消/失焦清理、窗口大小变化、最大化和任务栏恢复。

## 故事 1：连续点击即可讲完

打开页面后，默认进入 S1。按窗口外右下角的主按钮连续点击，即可依次走完 10 个画面（含开场与完成）。每一步同步切换中间证据、右侧对话和底部讲述提示。

1. **开场**：林岚要把 64 卡配置缩到 32 卡，锁定 GBS=128、16K、模型 / Top-K 与 BF16 / FP32 数值策略，本轮不占卡。
2. **四处变化**：节点 / Rank、DP、微批、优化器分片。来源链接可以定位文件行。
3. **分组阻断**：world 已匹配 32，但 DP=4 无法按 split 口径组成 EP=8；非法草稿不生成容量柱。
4. **仅修 EP**：在候选副本改成 EP=4 后，首段理论 68.61 GiB 超过示例 64 GiB；尚未发生真实 OOM。
5. **解释容量**：每卡专家增加、激活翻倍、优化器分片关闭，联动展示前后逐 Stage 容量。
6. **选择 A / B**：A 减微批增累积（46.79 GiB）；B 增加重计算（33.14 GiB）。默认选 A，可点击候选卡或 Diff 顶栏切换。
7. **仿真缺口**：无匹配测量包，兼容性待核对，未执行 Tinker；不填虚构步时或收益。
8. **Diff 审阅**：在原 IDE 比较新草稿与所选候选，点击底部主按钮或“保留方案”。
9. **待验交付**：静态通过、理论可容纳，运行待验证；不需要先短测即可导出。
10. **完成**：下载 JSON 包，包含完整构造输入、规则版本、容量分项、A/B 候选、所选 Diff、恢复语义待验项和空运行引用。再次点击主按钮从头重演。

“上一步”用于回讲；从已保留状态退回 Diff 会恢复草稿，再选择其他方案。可选真机计划只记录目标主机、队列、截止时间、32 卡设备预算和最长占用时间，不提交作业。记录计划后重新导出可将其带入配置包。

本轮固定数据随本目录 `s1-evidence.js` 一起保存，非实时 MCP 结果。容量是 theoretical、未校准，非实际设备峰值。修改任何固定输入会使结果失效，不为自定义配置套用预置结论；“重置”保留用户编辑，需恢复完整样例时使用“演示设置 → 恢复初始工程”。新版样例使用独立 localStorage 键，旧版浏览器工程仍保留。

## 范围与来源
