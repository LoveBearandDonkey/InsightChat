# Third-party components and UI sources

The demo now lives in the InsightChat repository. Shared icons are resolved from `src/pic/icon/`; existing byte-identical icons are reused and missing icons are merged without overwriting existing assets. The public demo is self-contained and does not ship the private planning repository.

The demo is a presentation shell, not a redistributed Microsoft VS Code binary. It uses the following local components. No external CDN is needed at runtime.

Seti and upstream CSS were retrieved from the public Code - OSS repository for this implementation. npm package versions are pinned above. Shell changes preserve the original component licenses.

The virtual desktop, three wallpapers and initial window management code are reused from the user-provided InsightChat workspace. Its original files remain unchanged. The small Code-style SVG in assets/ is a local illustration, not part of the Microsoft distribution.

The standalone msAgent window additionally extracts the exact IDE glass/gradient variable blocks from `app/chat.css` into `vendor/insight-surface.css`, scoped to `.agent-client`. Its geometry and preview-expansion pattern are adapted from `app/desktop-chat.js` and the `wzh-chat-panel.is-visualizing` rules: source files remain unchanged. GUI topic/preview layout and TUI behavior are implemented locally; they do not use OpenAI product source code or claim to be Codex.

The msAgent conversation reuses `app/pages/chat.html` component structure and its original `wzh-chat-*` classes. `vendor/insight-chat.css` extracts section [7] of `app/chat.css`, scoped to `.agent-client`, with localized asset paths and a 12px text minimum. `vendor/insight-chat-dots.js` copies the self-contained welcome dot renderer from `app/assistant.js`, targeting the client for theme observation. Original icons and PNGs are copied to `assets/insight-chat/`. `agent-conversation.js` maps component IDs/content to the existing msAgent topic/task store; `agent-conversation.css` holds the explicit host layout, typography, and theme-table weak separator adaptations. No source workspace files are modified and no InsightChat backend is bundled.

The three client themes (计算 / 新无限 / 追光) follow the user-provided `主题表.md`. `agent-themes.css` extracts the original palette/semantic tokens from `app/chat.css`; `vendor/insight-surface.css` now scopes the original light overrides conditionally, allowing the original dark shell tokens to render 追光. Themes also apply to the client's dialogs and embedded task preview; the source workspace is unchanged.

The assistant settings dialog copies the original markup from `app/pages/chat.html`, the `settings-dialog.css` and `settings-skills.css` styles, and read-only catalog render snapshots from `settings-skills.js`, `settings-mcp.js`, and `settings-knowledge.js` into `vendor/insight-settings/`. Source classes and control entry points are retained; selectors are scoped, asset paths are localized, and text is kept at a 12px minimum. Original general icon colors follow the source theme-table palette. `agent-settings.js` disables unsupported integrations and maps navigation to the window-local modal; `agent-settings.css` adapts host bounds and the new msAgent MCP pages to the two user-supplied reference screenshots. No original controllers that access external services or user files are executed.

The 14 PNGs in `assets/reuse/` are copied byte-for-byte from the user-provided `compute-graph-viewer-wzh/launch-v2.html` preview assets. `manifest.json` records the source page, original image path, launch item, planning assessment and SHA-256. They retain the original demo models and values and illustrate existing designs; they are not evidence of a new run. No source demo files were changed.

The context-chip icons `folder.svg`, `localfile.svg`, `close.svg` and `addfile.svg` in `src/pic/icon/` are copied unchanged from the user-provided `src/pic/icon/`. The anchor, project-directory binding and hover controls follow `app/pages/chat.html`, `app/chat.css` and `app/assistant.js`, with IDs mapped to the local client and directory actions limited to its demonstration workspace.
